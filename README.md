# سامانه زنگ مدرسه

برنامه‌ی دسکتاپ ویندوز برای زمان‌بندی و پخش خودکار زنگ مدرسه با ساعت، بدون نیاز به اینترنت در زمان اجرا.

<br>

## ویژگی‌ها

| بخش | توضیح |
|---|---|
| **برنامه پیش‌فرض مدرسه** | برنامه‌ی زمانی آماده‌ی مدرسه ابتدایی ایران از ۷:۳۰ تا ۱۲:۳۰، همراه ۵ زنگ صوتی داخلی |
| **برنامه هفتگی** | تعریف زنگ برای هر روز هفته، با ترتیب دلخواه فایل‌های صوتی و تعداد تکرار |
| **کتابخانه صوتی** | بارگذاری فایل‌های `mp3`، `wav`، `m4a`، `ogg`، `aac`، پخش آزمایشی و حذف گروهی |
| **الگوها** | ساخت یک الگوی زمان‌بندی و اعمال آن روی چند روز به‌صورت یکجا |
| **داشبورد** | برنامه‌ی امروز، نزدیک‌ترین زنگ با شمارش معکوس، آمار سامانه |
| **گزارش فعالیت‌ها** | ثبت خودکار همه‌ی پخش‌ها و تغییرات |
| **به‌روزرسانی خودکار** | بدون نیاز به حذف و نصب مجدد؛ داده‌ها دست‌نخورده باقی می‌مانند |
| **پوسته روشن/تیره** | پیروی از تنظیمات ویندوز یا انتخاب دستی |
| **اجرای پس‌زمینه** | بستن پنجره، برنامه را در سینی سیستم نگه می‌دارد |
| **رابط کامل فارسی** | چیدمان راست‌به‌چپ، اعداد فارسی، بدون احراز هویت |

<br>

## نیازمندی‌ها

- ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)
- برای دریافت به‌روزرسانی: اتصال اینترنت (خود برنامه بدون اینترنت هم کار می‌کند)
- نیازی به نصب Node.js یا هر ابزار دیگری **روی سیستم مدرسه نیست**

<br>

## نصب

۱. فایل `School Bell System Setup <نسخه>.exe` را اجرا کنید.
۲. مسیر نصب را انتخاب کنید (پیش‌فرض: `C:\Program Files\School Bell System`).
۳. برنامه بلافاصله اجرا می‌شود. نیازی به ساخت حساب کاربری یا رمز عبور نیست.

> **هشدار ویندوز:** چون برنامه امضای دیجیتال ندارد، SmartScreen ممکن است هشدار بدهد.
> روی **More info** و سپس **Run anyway** بزنید.

<br>

## شروع سریع

برنامه از همان لحظه‌ی اول آماده‌ی کار است — **نیازی به تنظیم دستی ندارد**:

۱. **کتابخانه صوتی** ← پنج زنگ همراه برنامه از قبل ثبت شده‌اند.
۲. **برنامه هفتگی** ← شنبه تا چهارشنبه با ۸ زنگ از ۷:۳۰ تا ۱۲:۳۰ پر شده است.
۳. برنامه در پس‌زمینه اجرا می‌شود و در ساعت تعیین‌شده زنگ را پخش می‌کند.

### برنامه‌ی پیش‌فرض

| ساعت | رویداد | صدا |
|---|---|---|
| `۰۷:۳۰` | زنگ اول — آغاز کلاس‌ها | دو ضربه |
| `۰۸:۲۰` | زنگ دوم | تک‌ضربه |
| `۰۹:۱۰` | زنگ سوم | تک‌ضربه |
| `۰۹:۴۰` | پایان نوبت صبح | دو ضربه |
| `۱۰:۰۰` | زنگ چهارم — نوبت بعدازظهر | دو ضربه |
| `۱۰:۴۵` | زنگ پنجم | تک‌ضربه |
| `۱۱:۳۰` | زنگ ششم | تک‌ضربه |
| `۱۲:۳۰` | پایان کلاس — تعطیلی | سه ضربه |

برای بازگرداندن این برنامه در هر زمان (حتی بعد از ویرایش‌های شخصی):
**برنامه هفتگی ← 🏫 برنامه پیش‌فرض مدرسه** ← انتخاب روزها ← **اعمال برنامه پیش‌فرض**.

> ⚠️ این دکمه رویدادهای روزهای انتخاب‌شده را **جایگزین** می‌کند. روزهای انتخاب‌نشده دست‌نخورده می‌مانند.

پنج‌شنبه به‌طور پیش‌فرض خالی است، ولی در پنجره‌ی اعمال قابل انتخاب است.

### زنگ‌های همراه برنامه

پنج فایل صوتی داخل نصب وجود دارد که با **ریاضی خالص** ساخته شده‌اند
(پارتیل‌های ناهماهنگ با میرایی نمایی — همان ساختار طیفی زنگ واقعی)،
پس هیچ مسئله‌ی کپی‌رایتی ندارند:

| فایل | کاربرد |
|---|---|
| `bell-start.wav` | آغاز کلاس — دو ضربه‌ی روشن |
| `bell-single.wav` | زنگ تک‌ضربه‌ای |
| `bell-double.wav` | پایان نوبت — دو ضربه |
| `bell-triple.wav` | تعطیلی — سه ضربه |
| `bell-recess.wav` | زنگ کوتاه تفریح |

<br>

## داده‌ها کجا ذخیره می‌شوند

همه‌ی داده‌ها **بیرون از پوشه نصب** و در این مسیر نگهداری می‌شوند:

```
%APPDATA%\school-bell-system\
├── school-bell-data.json      برنامه‌ها، تنظیمات، الگوها، فایل‌های صوتی ثبت‌شده
├── school-bell-backup.json    نسخه پشتیبان غلتان
├── audio\                     فایل‌های صوتی
└── backups\                   نسخه‌های پشتیبان پیش از هر به‌روزرسانی
```

نصب مجدد یا به‌روزرسانی برنامه **هرگز** این پوشه را دست نمی‌زند.
از مسیر **تنظیمات ← باز کردن پوشه داده‌ها** می‌توانید مستقیم به آن بروید.

<br>

## به‌روزرسانی خودکار

برنامه هر ۴ ساعت و نیز هنگام اجرا، نسخه جدید را از مخزن GitHub بررسی می‌کند.

**تنظیمات ← به‌روزرسانی برنامه**

- **بررسی نسخه جدید** — بررسی دستی
- **دانلود نسخه جدید** — پس از یافتن نسخه جدید
- **نصب و راه‌اندازی مجدد** — پس از کامل شدن دانلود

پیش از نصب هر به‌روزرسانی، یک نسخه پشتیبان تاریخ‌دار از برنامه‌ها و فایل‌های صوتی
در `backups\` ساخته می‌شود (پنج نسخه‌ی آخر نگهداری می‌شود).

> اگر شبکه مدرسه دسترسی به `github.com` را مسدود کند، بررسی به‌روزرسانی ناموفق می‌شود.
> در این حالت باید نسخه جدید را دستی نصب کنید؛ داده‌ها باز هم حفظ می‌شوند.

<br>

## ساختار پروژه

```
src/
├── main/                  پروسه اصلی (Node.js)
│   ├── main.js            پنجره، منو، سینی سیستم، به‌روزرسانی، پروتکل app://
│   ├── preload.js         تنها پل ارتباطی با رندرر

│   ├── audio-player.js    پخش صوتی
│   ├── data-manager.js    ذخیره‌سازی JSON با نوشتن اتمیک
│   └── default-schedule.js برنامه‌ی پیش‌فرض مدرسه ایران
├── renderer/              رابط کاربری
│   ├── index.html
│   ├── css/               توکن‌های طراحی، پوسته روشن/تیره
│   └── js/                ماژول‌های ES
└── audio/                 پنج زنگ همراه برنامه (ساخته‌شده با ریاضی)
```

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| زنگ پخش نمی‌شود | **کتابخانه صوتی** ← دکمه‌ی پخش کنار فایل را بزنید تا خروجی دستگاه بررسی شود. اگر باز هم صدایی نبود، مشکل از تنظیمات صدای ویندوز است، نه از برنامه. |
| صدا خیلی کم یا زیاد است | **تنظیمات ← میزان صدا** را تنظیم کنید (۰ تا ۱۰۰). |
| برنامه هنگام روشن شدن ویندوز اجرا نمی‌شود | **تنظیمات ← اجرای خودکار با ویندوز** را فعال کنید. |
| برنامه در سینی گم شده | روی فلش کوچک کنار ساعت راست‌کلیک کنید و **باز کردن برنامه** را بزنید. |
| به‌روزرسانی «نسخه‌ای منتشر نشده» می‌گوید | هنوز هیچ Release منتشر نشده است. تا آن زمان نسخه جدید را دستی نصب کنید. |
| داده‌ها خراب شده‌اند | از `backups\` آخرین نسخه پشتیبان را روی `school-bell-data.json` بگذارید. |
| برنامه باز نمی‌شود | پوشه `%APPDATA%\school-bell-system` را به نام `school-bell-system.old` تغییر نام دهید و دوباره اجرا کنید. |
